# Bounded pilot rationale and primary-source comparison

Potential user: a release analyst investigating delayed binary adverse events before a canary decision. Potential buyer: a platform/release team already retaining per-unit enrollment and outcome timestamps. The costly failure is treating faster completed outcomes as representative when adverse outcomes reveal later. Conversely, repeatedly waiting without knowing which pending cell drives uncertainty can waste analyst time. These are workflow hypotheses, not measured customer facts.

The executable contrast gives the same synthetic logs, weights, alpha and margins to sequential pending, fixed pending and completed-only methods. At an early look, 60% of canary adverse events have future observation timestamps; 10% of control events are adverse and observed. Completed-only can suggest ACCEPTABLE while full pending evidence is INCONCLUSIVE. At the late all-observed look, the large adverse difference is HARMFUL. A separately callable all-observed complete-data baseline equals the main method. This is a demonstrated engineering combination of declared-policy identity, temporal replay, retained missing denominators and per-cell time-uniform uncertainty; it is not a new concentration inequality.

[Argo Rollouts](https://argoproj.github.io/argo-rollouts/features/analysis/) already orchestrates metric analysis, delays and inconclusive runs. [Howard et al.](https://arxiv.org/html/1810.08240v9) already provides established confidence-sequence methods. CanaryBound supplies local, inspectable delayed binary log evidence for its narrow explicit model; no claim is made that either source lacks this exact capability. Integration is aggregate JSON or SDK output for a human-reviewed analysis step; this package does not install an Argo plugin or change a rollout.

A pilot should validate enrollment completeness, outcome definitions, timestamps, stationary cell means and the independence declaration on de-identified historical data before interpreting population labels. Track reviewer effort to identify pending cells, agreement with fully revealed outcomes, fraction remaining inconclusive, and compute cost on representative logs. Predeclare success metrics and policy thresholds; do not tune margins to make the example pass. Unknown: actual customer adoption, commercial willingness to pay, analyst time saved, revenue, production benefit and remote CI status. No operating-safety prediction is made from synthetic experiments.
