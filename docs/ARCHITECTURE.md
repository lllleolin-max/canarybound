# Architecture and operational boundary

`make_manifest` validates and snapshots operator declarations as immutable tuples and exact Fractions. `fingerprint` binds every event to the declaration. `analyze` validates the entire snapshot, resolves stable identities independent of file order, checks temporal consistency, selects assigned/observed records at the wall-clock look, retains pending denominators, and builds per-cell and fixed-weight aggregate enclosures. `Evidence` and `Interval` are frozen SDK objects; serialized endpoints are decimal strings preserving outward precision. A fingerprint is an identity binding, not a signature or authenticity claim.

CLI adapters enforce strict UTF-8 JSON, duplicate-field rejection, bounded files/lines, exclusive output channels and input/output alias checks. Results carry aggregate counts and separate finite/population labels. No persistent database, telemetry, network calls, remote metrics query, rollout controller or automatic deployment action is implemented. Logs are snapshots: append stable assignments and revelations externally, then analyze again. Wall-clock looks may move backward without mutating stored results.

Manifest identity uses a canonical hexadecimal exact-rational representation so valid scientific-notation alpha never depends on Python's decimal integer-string digit guard. `Manifest.as_dict()` is that identity representation, not the operator JSON input schema. Bound calculations use dedicated Decimal contexts and preserve the invoking application's context, traps and flags.

Time O(E + K log K) and memory O(E + K), E events and K strata, excluding bounded-precision integer costs. Exact rational denominator sizes are bounded by the numeric validation limit. Limits: at most 32 strata, 100000 events, 64 KiB manifest, 64 MiB log and 4096 bytes per line; IDs are 1..128 ASCII characters. Decimal numeric inputs have at most 128 coefficient digits, input strings at most 256 characters and exponent magnitude at most 10000. Negative/zero alpha and nonfinite numbers are rejected; weights must sum exactly, not approximately. Scientific notation preserves very small declared alpha without float underflow. JSON numeric booleans never count as rates/outcomes/counts.

Unrecorded assignments, misclassified binary outcomes, forged timestamps or false sampling declarations cannot be discovered from this log. The conservative radius can require large cohorts; permanent missingness can prevent a conclusive result indefinitely. Fixed target weights do not adapt to realized traffic or observed outcomes. No causal effect, operational safety, production accuracy, income or adoption claim follows.

`method="fixed-pending"` and `method="completed-only"` are labeled comparison ablations. The first is pointwise Hoeffding applied repeatedly without alpha spending. The second deletes pending outcomes and uses pointwise intervals; informative revelation violates its assumed representativeness. The complete-data sequential baseline requires all target cells' assignments to be observed and produces identical output to the main method when that requirement holds.
